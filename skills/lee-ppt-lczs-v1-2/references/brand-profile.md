# 品牌档案

用于提取、确认和复用项目品牌信息。项目实际内容保存为项目根目录的 `02-品牌档案.md`。

## 字段

```text
品牌名称：
品牌英文名：
主品牌色：
常用辅色：
强调色：
背景色：
禁用色：
主 Logo：
子 Logo：
联合 Logo：
Logo 主次关系：
Logo 安全距离：
Logo 使用场景：
Logo 禁止方式：
企业 IP 形象：
产品 IP 形象：
IP 使用场景：
品牌字体：
视觉关键词：
禁用风格：
来源文件：
```

## 规则

- 优先级：用户本轮明确要求、正式品牌手册、用户提供素材、已确认旧 PPT、历史品牌档案、AI 规划。
- 不完整时只询问会影响设计或交付的字段。
- 不得根据通用行业词直接认定具体品牌；必须结合企业名称、Logo、正式资料或用户确认。
- Logo、子 Logo 和 IP 必须记录主次关系与允许使用场景。
- 用户修改后立即更新项目档案，后续阶段只读取最新确认版本。
- Demo、整套设计稿、最终 PPTX 和续作必须使用同一档案。
