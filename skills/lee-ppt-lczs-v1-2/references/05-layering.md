# 阶段 5：拆层

整套设计稿确认后，先确认拆层方式：

```text
请选择拆层方式：

1. 无字底图 + 原生文字
2. 无字底图 + 原生文字 + 指定图标
3. 无字底图 + 原生文字 + 指定图标 + 指定插画
4. 无字底图 + 原生可编辑文字 + 指定图标 SVG + 指定插画 PNG + 原生形状和线条

推荐方式将根据页面复杂度标注。回复 1、2、3、4，或回复 0 采纳推荐。
```

图标优先 SVG，兼容需要时可用透明 PNG；插画使用 PNG。图标拆图或生成 SVG 时必须尽量保留设计稿中的图标底色、描边、线型、圆角和比例。标签框、卡片和流程框默认保留在视觉底图；选择方式 4 且形状足够简单时，才拆为原生形状和线条。专业截图、复杂流程图和复杂贴图必须作为独立图片层保留，不得强制拆解或重画。

## 执行规范

- 按确认的页码范围连续完成，除非用户明确要求逐页确认或遇到实质冲突，否则不按单页暂停。
- 视觉底图不得含需编辑的信息文字、页码、正文标题、正文内容、关键数据、Logo 文案或授权需替换的署名信息。
- 装饰性文字不单独拆层，保留在视觉底图。表示当前幻灯片页序的数字属于 PPT 内页编码，默认拆为原生文本；步骤号、榜单号、章节号等内容结构数字属于序列号，默认保留在视觉底图。属性无法确定时按视觉组件处理并保留在底图；若用户指定拆出序列号，则按图标标准处理，保持底色、边框和位置。
- 严格保持确认稿的比例、坐标、缩放和层级，不得移动、重排或擅自改色。
- 正文素材文件以页面编号开头；封面和封底使用语义名称。
- 素材平铺存放在 `05-视觉底图/`、`05-插画PNG/`、`05-图标SVG/`、`05-专业贴图/`，不按页创建子目录。历史项目仍可读取 `backgrounds-no-text/` 和 `backgrounds-visual/`，但新项目使用中文编号目录。
- 选择方式 4 时，原生形状和线条只还原形状、填充、边框线型和颜色；不得凭空添加设计稿没有的投影、发光、渐变等装饰效果。若设计稿明显包含投影等效果，尽量还原；原生效果不稳定时保留在视觉底图，避免重复叠加。
- 建立 `05-素材使用清单.md`，记录每个拆出的图标、插画、专业贴图对应页码和最终 PPTX 使用状态；拆出的素材必须出现在合成 PPTX 中。
- 阶段 5 只产出拆层素材目录和 `05-素材使用清单.md`，不创建、复制、检查或导出任何 PPTX。拆图、SVG/PNG 生成和图片处理不强制使用 `presentations:Presentations`；进入阶段 6 后，所有 PPTX 操作仍必须使用该能力。

## 冲突处理

如果拆层要求与确认设计稿、品牌档案、素材格式或高保真还原发生冲突，必须先说明冲突条款、影响和推荐处理方式，等待确认后继续，不得静默改变规范。
