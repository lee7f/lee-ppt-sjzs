# 使用者档案

用于封面、封底、署名和联系方式填充。项目实际内容保存为项目根目录的 `02-使用者档案.md`。

## 信息分类

- 基础身份：姓名、职位、所属企业、所属部门、演讲身份、署名方式。
- 联系方式：邮箱、手机、微信、个人主页、企业官网、二维码。
- 视觉素材：个人照片、头像、个人 IP 形象。
- 展示授权：封面允许显示、封底允许显示、隐私限制。
- 来源记录：来源文件、确认时间、确认人。

## 规则

- 姓名、职位和企业仅在页面需要时确认；联系方式和视觉素材均为可选。
- 不得推测或生成邮箱、电话、微信、二维码及个人简介。
- 必须确认哪些字段允许出现在封面或封底；未授权信息不得写入设计稿或 PPTX。
- 个人照片、头像和个人 IP 仅按用户授权范围使用。
- 用户修改后立即更新项目档案，封面、封底、续作和 QA 读取同一版本。
- QA 检查实际页面与档案一致，并确认没有泄露受限信息。
