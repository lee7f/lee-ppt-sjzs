# 阶段 2：范围与页纲

开始前简要归纳阶段 1 已确认的信息。自动汇总资料和对话，不展示内部任务分型或推理依据。资料之外的补全标注“AI 规划”。

信息不足或冲突时，只询问影响内容、页数、品牌、封面封底或交付的必要问题。页面内容或页数由 AI 规划时必须逐页写明，并创建 `02-页纲.md`。

## 默认值

- 页面比例：`16:9`，除非用户另有要求。
- 品牌：优先使用已确认的 `02-品牌档案.md`；没有品牌档案时再从资料识别或由 AI 规划。
- 字体：Windows 使用 Microsoft YaHei UI 与 Segoe UI；Mac 使用 PingFang SC 与 SF Pro；终端未知或跨平台交付时使用 Microsoft YaHei 与 Arial 托底。
- 封面和封底：默认包含，不显示编号；正文从 `01` 起连续编号。
- 原生文字：行高 `1.2`、内边距 `0`。
