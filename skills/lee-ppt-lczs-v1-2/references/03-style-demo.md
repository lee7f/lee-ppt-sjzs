# 阶段 3：风格与 Demo

开始前简要归纳已确认的主题、页纲、品牌和使用者信息。一次提出 3 个适配方向，并同步为每个方向生成一张封面 Demo 和一张相同内容的正文 Demo。

不得仅用文字描述风格，不得使用拼接式宫格替代独立 Demo。根据任务使用可用的图像生成能力。

## 每组内容

- 风格名称与适合原因；
- 叙事、信息密度、视觉语言和主要风险；
- 封面 Demo；
- 与页纲匹配的同一正文页 Demo。

三组正文 Demo 使用相同标题、文案和页码，仅改变版式、色彩、图形和质感。Demo 必须使用已确认的品牌档案；封面只使用已确认且允许展示的使用者信息。不得虚构 Logo、IP、姓名或联系方式。

保存结构：

```text
03-风格Demo/
├── 03-A-<风格名>/
├── 03-B-<风格名>/
├── 03-C-<风格名>/
└── 03-融合方案/  # 按需
```

每组说明后紧跟对应封面和正文 Demo，并附实际文件链接。用户指定的参考风格必须作为三个方向之一。

## 选择与融合

展示后提示：

```text
请选择风格编号；可选择单个或多个。回复 0 可采纳标注的推荐风格。
```

多风格时确认主风格、辅助风格和融合比例，再生成封面与正文融合 Demo。融合 Demo 确认后才能进入阶段 4。

已确认 Demo 直接复用到整套设计稿，不得重复生成，除非用户明确要求重做。

## 阶段完成

```text
阶段 3 已完成。请确认是否进入阶段 4：整套设计稿。
```
