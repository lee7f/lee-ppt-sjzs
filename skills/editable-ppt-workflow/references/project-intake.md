# 项目填写单

将以下字段作为记录模板或对话引导。核心内容或附件先确认；基础信息进入阶段 2 后按“目标场景 → 受众 → 品牌要求 → 页面比例 → 内容页数”的顺序逐题询问，等待用户回答上一题后再问下一题。若用户已明确给出某项则直接采用，未给出时可给出 AI 推荐；用户回复 `0` 表示采纳当前推荐或默认值。

```text
任务类型：[新建 PPT / 参考图转可编辑 PPT / 混合]
主题与一句话目标：[必填]
目标场景：[汇报 / 路演 / 培训 / 方案提案 / 复盘；默认 AI 推荐；其他需求由用户直接写明]
受众：[老板 / 客户 / 团队 / 投资人 / 学员；默认 AI 推荐；其他受众由用户直接写明]
品牌要求：[默认保留或启用已知品牌色；提示用户可上传 logo、IP 形象、品牌素材]
页面比例：[默认 16:9；如有不同需求由用户直接写明]
建议内容页数（不含封面和封底）：[AI 根据内容密度、目标场景、受众和演讲时长推荐]
用户确认的内容页数（不含封面和封底）：[未指定时采用建议数量；用户直接写页数则记录为用户需求]
核心内容或附件：[必填]
演讲时长：[AI 推荐]
风格偏好：[高级简洁 / 咨询报告 / 科技感 / 品牌发布 / 小红书感 / 杂志感 / 自定义；默认 AI 推荐]
参考文件：[无]
可编辑范围：[所有文字与数字；视觉重建时仅文字和数字]
输出语言：[中文]
交付路径与文件名：[当前工作区 outputs/]
是否先看风格 Demo：[是；若直接制作则否]
```

## 推荐选择

| 场景 | 叙事结构 | 信息密度 | 推荐视觉 |
| --- | --- | --- | --- |
| 项目复盘 | 背景 → 目标 → 过程 → 结果 → 复盘 → 行动 | 中 | 关键数据 + 过程证据 |
| 方案/提案 | 问题 → 洞察 → 方案 → 价值 → 路线 → 请求 | 低至中 | 强主视觉 + 少量框架 |
| 知识分享 | 钩子 → 概念 → 方法 → 案例 → 总结 | 中 | 图解或单一隐喻 |
| 个人表达 | 钩子 → 立场 → 故事 → 转折 → 收束 | 低 | 编辑感照片或抽象材质 |

## 风格卡输出格式

每个候选风格用五行描述：名称；适配原因；配色与字体；构图/视觉母题；风险或限制。选择后记录一个明确的风格契约：色板、字体、字号阶梯、留白、圆角/描边、图像处理、页码和禁止项。

## 页数规划规则

- 内容页数只计算正文内容页，不包含封面和封底。
- 规划时先给出建议内容页数，并说明推荐理由，例如信息密度、演讲时长、受众耐心或汇报场景。
- 用户直接写明或确认内容页数时，叙事地图必须精确规划对应数量的正文页。
- 封面、目录、过渡页和封底是否需要，应单独说明；不得把它们偷偷计入用户指定的内容页数。
- 用户不指定页数时，采用建议数量，并说明“内容页 N 页，另含封面/封底”。
