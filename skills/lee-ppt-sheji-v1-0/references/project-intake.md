# 项目填写单

将以下字段作为记录模板或对话引导。核心内容或附件先确认；基础信息进入阶段 2 后，默认先从资料中自动读取和分析，再一次性输出“阶段 2：综合确认结果”。只有资料不足、冲突严重或用户明确要求逐项确认时，才启用原 9 题兜底模式。

## 阶段 2 自动读取范围

优先从以下来源提取信息：

1. 文档标题、正文标题、摘要、目录、章节结构
2. 旧 PPT 的封面、页脚、母版、配色、字体、页面比例、页数
3. PDF、截图、图片中的文字、logo、品牌色、画面比例
4. 用户在对话中已经说明的目标、受众、风格、页数、限制条件
5. 文件名、文件夹名、附件名称中的主题和场景线索

## 阶段 2 可信度

每个识别结果后必须标注可信度：

- 高：资料中有明确文字、标题、logo、尺寸、页数或用户原话支持
- 中：资料中多处出现相关线索，可以合理推断
- 低：仅能根据内容类型、语气或结构弱推断
- AI 规划：资料中没有明确答案，由 AI 基于需求文件给出建议
- 未识别：资料中没有足够线索，且不适合 AI 直接规划

不得把低可信推断或 AI 规划包装成资料中的确定结论。

可信度展示规则：

- 高：`<span style="color:#F5B301">★★★</span>`
- 中：`<span style="color:#F5B301">★★</span>`
- 低：`<span style="color:#F5B301">★</span>`
- AI 规划：直接写 `AI 规划`
- 未识别：直接写 `未识别`

## 页面比例

页面比例默认写死为 `16:9`。阶段 2 不主动提供其他比例选项，也不提示用户可修改。除非用户主动明确提出其他比例，否则始终按 `16:9` 执行。

## 品牌色

品牌色必须优先执行关键词识别。只要参考资料、文件名、正文、截图 OCR、旧 PPT 文本或用户对话中任意位置出现以下关键词之一，必须首先推荐品牌色 `#0E76C3`：

- 普乐师
- Plus
- flux
- fluxPlus
- FluxMens
- 即时零售
- 数字化动销
- 动销场景
- 动销

如果没有命中以上关键词，但资料中存在明确品牌色，则采用资料中的品牌色，并标注依据。

如果既没有命中关键词，也没有明确品牌色，AI 必须根据需求文件的行业属性、内容气质、受众和使用场景给出一套主色方案，标注为“AI 规划”。

## 字体

字体固定提供 3 套默认可选方案：

1. Mac 系统默认字体方案
2. Win 系统默认字体方案
3. 微软雅黑托底方案

阶段 2 需要先从用户对话、文件来源、编辑环境描述中判断使用终端。用户明确说明使用 Mac 或 Windows 时，直接推荐对应系统默认字体方案；用户未说明终端、需要多人协作、客户交付或跨终端编辑时，默认推荐微软雅黑托底方案，并提示使用者提前安装或确认环境支持，以减少跨设备错位和字体授权风险。

字体方案必须写清楚标题、正文、英文、大数字四类文本标准：

```text
Mac 系统默认字体方案：
标题：PingFang SC Semibold
正文：PingFang SC Regular
英文：SF Pro Display / SF Pro Text
大数字：SF Pro Display Semibold

Win 系统默认字体方案：
标题：Microsoft YaHei UI Semibold
正文：Microsoft YaHei UI Regular
英文：Segoe UI
大数字：Segoe UI Semibold

微软雅黑托底方案：
标题：Microsoft YaHei Bold
正文：Microsoft YaHei Regular
英文：Arial
大数字：Arial Bold
```

## 阶段 2 综合确认格式

必须使用有序列表，方便用户按序号提出修改意见。每一项使用三行结构：第一行写序号、字段名和加粗结果；第二行单独写可信度；第三行单独写依据。不得把结果、可信度和依据挤在同一行。顺序固定如下：

阶段 2：综合确认结果

1. 任务类型：**新建 PPT**
   可信度：<span style="color:#F5B301">★★★</span>
   依据：用户要求“根据文档策划制作pptx”
2. 主题与一句话目标：**xxx**
   可信度：<span style="color:#F5B301">★★</span>
   依据：来自文档标题和正文高频内容
3. 目标场景：**路演**
   可信度：<span style="color:#F5B301">★★</span>
   依据：内容包含商业价值、方案介绍、投资表达
4. 主要受众：**客户、投资人**
   可信度：<span style="color:#F5B301">★★</span>
   依据：文档多次出现客户价值、融资/商业化表达
5. 页面比例：**16:9**
   可信度：<span style="color:#F5B301">★★★</span>
   依据：默认演示比例
6. 品牌色：**#0E76C3**
   可信度：<span style="color:#F5B301">★★★</span>
   依据：资料中出现“普乐师/动销”等品牌或业务关键词
7. logo：**无**
   可信度：<span style="color:#F5B301">★★★</span>
   依据：附件中未识别到明确 logo
8. IP 形象：**无**
   可信度：<span style="color:#F5B301">★★★</span>
   依据：附件中未识别到人物/IP 素材
9. 字体：**微软雅黑托底方案**
   可信度：AI 规划
   依据：未检测到固定编辑终端，推荐多终端适配方案；标题 Microsoft YaHei Bold，正文 Microsoft YaHei Regular，英文 Arial，大数字 Arial Bold
10. 正文页数：**4 页**
    可信度：<span style="color:#F5B301">★★</span>
    依据：内容密度适合短版路演结构
11. 封面/封底：**不需要**
    可信度：<span style="color:#F5B301">★</span>
    依据：用户未明确要求

“更多要求”不再作为固定字段输出。用户如有额外要求，会在对话中主动提出；如用户已主动提出，则合并进对应字段或在确认表末尾增加：

12. 特殊要求：**xxx**
    可信度：<span style="color:#F5B301">★★★</span>
    依据：用户原话

## 阶段 2 追问规则

输出综合确认表后，只用一句话追问：

```text
是否下一步？
```

不得重复解释 `0` 的含义。用户若需要修改，可直接按确认表序号提出修改意见，例如“改第 6 条为黑金风格”或“第 10 条改成 6 页”。页面比例不进入追问项，默认始终执行 `16:9`。

## 原 9 题兜底模式

只有在以下情况才启用逐题询问：

1. 用户没有提供任何可分析资料
2. 资料极少，无法形成综合确认表
3. 用户明确要求逐项确认
4. 自动读取结果冲突严重，无法可靠归纳

## 推荐选择

| 场景 | 叙事结构 | 信息密度 | 推荐视觉 |
| --- | --- | --- | --- |
| 项目复盘 | 背景 → 目标 → 过程 → 结果 → 复盘 → 行动 | 中 | 关键数据 + 过程证据 |
| 方案/提案 | 问题 → 洞察 → 方案 → 价值 → 路线 → 请求 | 低至中 | 强主视觉 + 少量框架 |
| 知识分享 | 钩子 → 概念 → 方法 → 案例 → 总结 | 中 | 图解或单一隐喻 |
| 个人表达 | 钩子 → 立场 → 故事 → 转折 → 收束 | 低 | 编辑感照片或抽象材质 |

## 页数规划规则

- 内容页数只计算正文内容页，不包含封面和封底。
- 规划时先给出建议内容页数，并说明推荐理由，例如信息密度、演讲时长、受众耐心或汇报场景。
- 用户直接写明或确认内容页数时，叙事地图必须精确规划对应数量的正文页。
- 封面、目录、过渡页和封底是否需要，应单独说明；不得把它们偷偷计入用户指定的内容页数。
- 用户不指定页数时，采用建议数量，并说明“内容页 N 页，另含封面/封底”。
