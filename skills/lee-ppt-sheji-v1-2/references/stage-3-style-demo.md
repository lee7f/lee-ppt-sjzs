# 阶段 3：风格建议与关键页 Demo 确认

阶段 3 必须一次性推荐 4 个适配风格，并同步生成 Demo。不得先只给文字风格说明。

## Demo 要求

- 每个风格方向生成 2 张独立 Demo：封面页 + 内页。
- Demo 必须带真实文案。
- 不得用一张四宫格风格板替代 4 组 Demo。
- 涉及生成图片时调用 `imagegen`。

## 风格说明

每个风格方向说明：

- 适用场景
- 叙事结构
- 信息密度
- 推荐视觉
- 适合原因

用户可选择单一风格，也可选择多风格融合。融合时必须明确主风格和辅助风格。

## 融合风格

用户选择多风格融合时，先生成“融合风格 Demo”，至少包含封面 + 内页。

融合 Demo 必须写清：

- 主风格
- 辅助风格
- 融合比例
- 保留元素
- 弱化元素

用户确认融合 Demo 后，才能进入阶段 4。

## 参考素材

如果用户上传素材并指定为风格参考，必须把该素材风格插入 4 个可选风格中，并标注来源。

## 确认规则

用户选择单一风格后，默认表示对该组 Demo 的核心页面样式满意。后续整套 image 设计稿应沿用被确认 Demo 的版式语言、色彩、质感和页面样式。
