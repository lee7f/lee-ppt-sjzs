# 阶段 2：综合信息确认

阶段 2 不默认逐题询问。完成阶段 1 后，先从资料中自动读取信息，再一次性输出“阶段 2：综合确认结果”。

只有资料不足、冲突严重或用户明确要求逐项确认时，才启用兜底提问。

## 自动读取范围

- 使用者身份、受众、使用场景、演讲时长。
- 主题、作者、联系方式。
- 企业品牌信息、品牌色、logo、IP 形象。
- 字体、页面比例、页面数量、封面和封底。
- 文档标题、正文标题、摘要、目录、章节结构。
- 旧 PPT 的封面、页脚、母版、配色、字体、比例、页数。
- PDF、截图、图片中的文字、logo、品牌色、画面比例。
- 文件名、文件夹名、附件名中的主题和场景线索。

## 可信度

- 高：资料中有明确文字、标题、logo、尺寸、页数或用户原话支持。
- 中：资料中多处出现相关线索，可以合理推断。
- 低：仅能根据内容类型、语气或结构弱推断。
- AI 规划：资料中没有明确答案，由 AI 基于需求给出建议。
- 未识别：资料中没有足够线索，且不适合 AI 直接规划。

展示规则：

- 可信度直接写文字，不使用 HTML、星级或颜色。
- 可选值固定为：高、中、低、AI 规划、未识别。

## 页面比例

页面比例默认写死为 `16:9`。除非用户主动明确提出其他比例，否则始终按 `16:9` 执行。

## 品牌色

优先执行关键词识别。只要资料、文件名、正文、截图 OCR、旧 PPT 文本或对话中出现以下任一关键词，首先推荐品牌色 `#0E76C3`：

- 普乐师
- Plus
- flux
- fluxPlus
- FluxMens
- 即时零售
- 数字化动销
- 动销场景
- 动销

若未命中关键词，但资料中有明确品牌色，采用资料品牌色并标注依据。若都没有，基于行业、内容气质、受众和场景给主色方案，标注“AI 规划”。

## 字体

字体固定在 3 套方案中选择：

```text
Mac 系统默认字体方案：
标题：PingFang SC Semibold
正文：PingFang SC Regular
英文：SF Pro Display / SF Pro Text
大数字：SF Pro Display Semibold

Win 系统默认字体方案：
标题：Microsoft YaHei UI Semibold
正文：Microsoft YaHei UI Regular
英文：Segoe UI
大数字：Segoe UI Semibold

微软雅黑托底方案：
标题：Microsoft YaHei Bold
正文：Microsoft YaHei Regular
英文：Arial
大数字：Arial Bold
```

## 输出格式

必须使用标题：

```text
阶段 2：综合确认结果
```

必须使用有序列表。每项三行：

```text
1. 字段名：**结果**
可信度：...
依据：...
```

字段顺序固定：

1. 任务类型
2. 需求类型
3. 主题与一句话目标
4. 目标场景
5. 主讲人身份
6. 主要受众
7. 演讲时长
8. 页面比例
9. 品牌色
10. logo
11. IP 形象
12. 字体
13. 正文页数
14. 封面/封底
15. 作者/联系方式

用户有额外要求时，合并进对应字段，或在末尾增加“特殊要求”。

## 追问

综合确认表后，只问：

```text
是否下一步？
```
