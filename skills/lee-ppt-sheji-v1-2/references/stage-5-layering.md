# 阶段 5：设计稿拆层与素材整理

用户确认带文案 image 设计稿后，必须先确认拆层维度，不得直接拆层。

## 默认拆层

- 底图层：整页无字背景 PNG。
- 文字层：PPT 原生可编辑文字，行高 `1.2`，文本框跟随文字大小，内边距 `0`。

## 可选拆层

```text
1. 插画层：独立 PNG，只输出 PNG，不输出 SVG
2. 图标层：独立 SVG，只输出 SVG，不输出 PNG
3. 标签框 / 输入框 / 卡片样式：PPT 原生形状
```

## 询问文案

```text
请选择拆层维度：
0. 默认：整页无字背景 PNG + PPT 原生文字
1. 增加插画层
2. 增加图标层
3. 增加标签框 / 输入框 / 卡片原生形状

可输入 0、1、2、3 或组合编号，如 12、13、23、123。
```

## 输入规则

- `0`：按默认拆层执行。
- `1`、`2`、`3` 或组合编号：在默认基础上增加对应层级。
- `123`：三类可选层级全选，不再需要整页底图层。

只要用户未选择 `123`，就必须保留整页无字底图层。

## 文件夹规则

素材文件夹不按页分子文件夹：

```text
backgrounds-no-text/
├── 01-background.png
├── 02-background.png
└── ...

illustrations-png/
├── 01-main-illustration.png
├── 02-process-illustration.png
└── ...

icons-svg/
├── 01-arrow-icon.svg
├── 02-data-icon.svg
└── ...
```

只有用户选择 `1` 时才创建 `illustrations-png/`。
只有用户选择 `2` 时才创建 `icons-svg/`。
只有用户选择 `3` 时才把标签框、输入框和卡片样式拆为 PPT 原生形状。

所有素材文件名前必须加入对应页码编号。
