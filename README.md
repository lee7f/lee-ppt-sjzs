# lee-ppt-sheji

Codex 可编辑 PPT 设计技能仓库，用于把文案、旧 PPT、截图、PDF、图片素材或品牌资料，整理成高质量、可追溯、可编辑的 PowerPoint 文件。

## 版本

- `lee-ppt-sheji-v1-1`：V1.1 完整阶段流程版本，包含需求分型、资料解析、风格 Demo、页面规划、拆层确认和验收规则。
- `lee-ppt-sheji-v1-2`：V1.2 精简阶段文档版本，将阶段说明拆分到独立 reference 文件，便于维护和调用。

## 仓库结构

```text
skills/
├── lee-ppt-sheji-v1-1/
│   ├── SKILL.md
│   └── references/
└── lee-ppt-sheji-v1-2/
    ├── SKILL.md
    ├── agents/
    └── references/
```

## 下载包

- `lee-ppt-sheji-v1-1.zip`
- `lee-ppt-sheji-v1-2.zip`

## 安装方式

将需要的版本文件夹复制到 Codex 技能目录：

```text
skills/lee-ppt-sheji-v1-1
skills/lee-ppt-sheji-v1-2
```

也可以下载对应 zip，解压后把其中的技能文件夹放入 Codex 技能目录。

## 说明

`SKILL.md` 顶部的技能名使用 `v1-1`、`v1-2`，这是为了符合技能命名规范；标题和说明中保留 `V1.1`、`V1.2` 的版本表达。
