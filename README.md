# lee-ppt-sheji

Codex 可编辑 PPT 设计技能仓库，用于把文案、旧 PPT、截图、PDF、图片素材或品牌资料，整理成高质量、可追溯、可编辑的 PowerPoint 文件。

## 版本

- `lee-ppt-sheji-v1-0`：V1.0 阶段流程版本，包含风格确认、文案预览、无字底图和可编辑文字层交付规则。
- `lee-ppt-sheji-v1-1`：V1.1 完整阶段流程版本，包含需求分型、资料解析、风格 Demo、页面规划、拆层确认和验收规则。
- `lee-ppt-lczs-v1-2`：V1.2 完整交付版本，包含资料解读、3 组风格 Demo、整套设计稿、拆层、可编辑 PPTX 合成与强制 QA。

## 安装方式

将需要的版本文件夹复制到 Codex 技能目录：

```text
skills/lee-ppt-sheji-v1-0
skills/lee-ppt-sheji-v1-1
skills/lee-ppt-lczs-v1-2
```

也可以下载对应 zip，解压后把其中的技能文件夹放入 Codex 技能目录。

## 说明

`SKILL.md` 顶部的技能名使用小写英文、数字和连字符，并以 `v1-0`、`v1-1`、`v1-2` 表达版本号，以符合技能命名规范。
